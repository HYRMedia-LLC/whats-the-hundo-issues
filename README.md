# What's The Hundo? Issue Tracker

Use this public repository to report bugs, incorrect information, event problems, and feature requests for the What's The Hundo? iOS and Android apps.

- [Browse open issues](https://github.com/HYRMedia-LLC/whats-the-hundo-issues/issues)
- [Report a problem or request a feature](https://github.com/HYRMedia-LLC/whats-the-hundo-issues/issues/new/choose)

Before you open an issue, search the existing issues to avoid duplicates. Add the **iOS** or **Android** label to identify the affected app. Add **Information Accuracy** or **Event Issues** when it applies.

Include clear steps, expected behavior, actual behavior, and screenshots when they help explain the problem. For information or event reports, include the affected Pokemon, raid, event, date, and timezone when possible.

The application source code is maintained in private repositories. This repository does not contain product source code.
